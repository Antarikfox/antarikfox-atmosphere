# Изменения

## 2.0.1-beta.1 — 2026-11-04

Первый подготовленный публичный бета-релиз.

- Убраны домашние entity_id автора; без датчиков карточка показывает подсказку настройки.
- Отдельные исходники, воспроизводимая сборка и готовый файл для HACS.
- Русская инструкция, публичное демо, шаблон отчёта об ошибке и проверки GitHub Actions.
- Сохранены графитовый корпус, живые шкалы, туман, блики, искры, окна показателей и визуальный редактор версии 2.0.0.

## 2.0.0 — 2026-11-04

Исходная персональная версия Atmosphere. Публикация этой версии на GitHub не предполагается: для сообщества предназначена обезличенная бета выше.
